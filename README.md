# PromNET Statisztika — Google Tag Manager template

Cookie-free website analytics from Hungary: [statisztika.promnet.hu](https://statisztika.promnet.hu/).
No cookies, no IP storage — no cookie consent banner needed. Free for one website.

## Usage

1. Create your website at statisztika.promnet.hu and copy the **website ID** (`data-website-id` in the tracking code).
2. In Google Tag Manager: Templates → Search Gallery → **PromNET Statisztika** → Add.
3. New tag → PromNET Statisztika → paste the website ID → trigger: **All Pages** (or Initialization – All Pages) → Publish.

Goals: add `data-umami-event="name"` to any button or link, it appears under “Célok”.

---
